# Chaos

Versión propia en 2D del mod *Custom Hero Chaos* de Dota 2, para jugar en el navegador contra 7 rivales de la IA.

- Plan y estado: [`docs/PLAN.md`](docs/PLAN.md)
- Cómo es el mod original: [`docs/REFERENCIA-CHC.md`](docs/REFERENCIA-CHC.md)

Para abrirlo, serví la carpeta y entrá a `http://localhost:8768`:

```
py -m http.server 8768
```

- Juego: `http://localhost:8768/`
- Pruebas: `http://localhost:8768/tests.html`
- Consulta de los datos de Dota: `http://localhost:8768/datos.html`

Proyecto de fans, sin relación con Valve ni con los creadores del mod.
